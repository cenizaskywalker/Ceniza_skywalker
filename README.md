# Ceniza Portfolio — Redesign

This is the first complete redesign of the Ceniza Roblox UI Designer portfolio.

## Files
- index.html — page structure and content
- style.css — visual system, responsive layout and animations
- script.js — navigation, scroll reveal, gallery modal and Discord copy button
- ImagesWorks/ — local portfolio assets

## To publish on GitHub Pages
Replace the files in the repository with these files and keep the `ImagesWorks` folder beside `index.html`.
